# mouse-battery-indicator
鼠标托盘电量指示器，Windows 右下角托盘显示无线鼠标电量

## ✨ 支持说明
本版本只使用标准蓝牙BAS电池服务读取电量，不再发送任何2.4G HID私有指令
✅ 实测设备：迈从 MCHOSE A7 Pro 双模鼠标

> ⚠️ 重要：即使使用2.4G接收器玩游戏，鼠标也必须提前和电脑完成蓝牙配对，依靠蓝牙通道读取电量，全程不干扰2.4G通道，不会修改DPI。
> ❗ 阉割了BAS蓝牙电池服务的廉价鼠标无法读取。

## 🎨 电量颜色规则
- 电量 ＜ 20%：图标红色（低电量提醒）
- 电量 ＞ 80%：图标绿色
- 20% ≤ 电量 ≤ 80%：图标白色

## 📦 源码使用方式
### 环境依赖
Python 3.8+
```bash
pip install -r requirements.txt

### 下载解压后的完整使用步骤

1. **解压文件**
右键下载的 `Source code (zip)` 压缩包，选择「解压到当前文件夹」，解压后得到 3 个核心文件：

- `mouse_battery_tray.py`（主程序）
- `requirements.txt`（依赖清单）
- `README.md`（说明文档）

2. **两项前置准备**

- 电脑安装 Python 3.8 及以上版本，安装时**务必勾选「Add Python to PATH」**
- 先在 Windows 蓝牙设置里，和你的鼠标完成蓝牙配对（哪怕你用 2.4G 接收器玩游戏，这一步也必须做）

3. **安装运行依赖**

- 进入解压后的文件夹，在顶部地址栏输入 `cmd` 回车，打开命令行窗口
- 输入下面命令并回车，自动一次性装好所有需要的库：

```
pip install -r requirements.txt
```

4. **启动程序（后台静默运行，无黑窗口）**
在同一个命令行窗口输入：

```
pythonw mouse_battery_tray.py
```

回车后没有任何弹窗，右下角托盘会出现电量图标，每 5 秒自动刷新蓝牙电量。

5. **设置开机自启（可选）**

- 按 `Win + R`，输入 `shell:startup` 回车，打开系统启动文件夹
- 给 `mouse_battery_tray.py` 创建快捷方式，把快捷方式拖进启动文件夹即可

6. **退出程序**
右键右下角托盘的电量图标，点击「退出」即可关闭。

---

### 补充说明

- 程序全程不会向 2.4G 通道发送指令，**完全不会修改鼠标 DPI**
- 如果读不到电量，优先检查蓝牙是否保持连接、鼠标是否支持标准 BAS 电池服务
- 托盘图标被隐藏时，点右下角向上的箭头「^」就能找到
